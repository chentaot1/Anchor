# Harbor + Grove illustration style

- Flat vector, rounded forms, no sharp geometry, no pixel art, no emoji in production.
- Silhouette first: two species must stay distinct when filled black.
- Three LODs: Dock ~140dp (1–2 leaf clumps), Grid ~80dp (filled silhouette), Thumb 40dp.
- Palette: `#0A0E18` ground, `#74C69D` foliage, `#2D6A4F` trunks/soil, `#FFAB6B` chrome/lanterns, `#7EB8FF` water/plan, `#A78BFA` Think only.
- Scene layers: time-of-day sky → far hill → near hill → water + unlabeled tide → dock plank → plants → optional mist.
- Grove plants are 2D `PlantIllustration`. One Kenney 3D model on FocusCanvas only.
- Empty dock is a place. No Sprout label on Grove. No dead trees.
