# Windows 1.0.6

Anchor's original code is now GPLv3 (version 3 only). Full license texts and third-party notices are bundled and can be read from Settings. Earlier MIT grants remain valid; third-party components retain their own licenses.

Removed all plant models, the shared plant catalog and the unused plant argument in the focus canvas. The harbor keeps focus milestones using original Compose geometry instead of image assets with unverified provenance. Planning, timers, focus credit, habits and saved records continue to work.

The MSI and EXE installers include Microsoft OpenJDK 17.0.20.1+1-LTS, its unchanged legal directory and Access Bridge. Installers remain unsigned. Matching Anchor and OpenJDK source archives accompany the release; build instructions are in each archive. The separate model weights and `llama-server` are user-installed and retain their upstream licenses.

323 Windows, 224 Android and six shared unit tests passed. MSI/EXE assembly, installer version and upgrade identity, packaged Access Bridge, legal texts, removal of plant/forest payloads and source/application privacy screens were verified. Physical screen-reader interaction was not repeated for this release.
